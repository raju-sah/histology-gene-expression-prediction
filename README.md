# Predicting spatial gene expression from H&E with pathology foundation models

Which genes can be predicted from H&E morphology on Xenium 5k data, and what makes a gene predictable?
Frozen embeddings from UNI2-h, Virchow2 and CONCH v1.5 (+ ImageNet ResNet50 baseline), linear / small-MLP heads,
patient/sample-level splits. See [ROADMAP.md](ROADMAP.md) for the plan and [PROGRESS.md](PROGRESS.md) for status.

## Layout
```
src/hestfm/    library code (data loading, splits, heads, metrics, pseudo-spots, analysis)
notebooks/     colab_*.ipynb  -- GPU work, run in Google Colab, write to Drive
scripts/       CLI entry points that turn data/ into reports/ (every reported number comes from a script)
tests/         pytest unit tests (synthetic data, no downloads)
configs/       YAML configs (tasks, samples, encoders, Drive paths)
data/          gitignored: meta/ (small HEST metadata), embeddings/ (downloaded from Drive)
reports/       tables + figures generated by scripts
paper/         LaTeX draft
```

## Setup
```bash
uv venv .venv --python 3.12
VIRTUAL_ENV=.venv uv pip install -r requirements.txt --index-strategy unsafe-best-match
.venv/bin/python -m pytest -q
```
